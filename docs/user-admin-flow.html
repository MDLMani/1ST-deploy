Detailed Pages & Fields — User App

Onboarding
Purpose: First-time intro, permissions request.
  • Pages: Welcome, Feature tour
  • Fields: none (informational)
Auth — Login / Signup
  • Login: email, password, optional remember me
  • Signup: name, email, password, phone, terms checkbox
  • Format: email validated, password min length 8, phone E.164 optional
Home / Feed
  • Contains: personalized cards, quick actions, promo banners
  • Data format: list of cards with id, title, summary, imageUrl, action
Browse / Discover
  • Filters: categories, sort, price/date
  • Format: paginated results; items include id,title,thumbnail,shortDesc,meta
Item Detail
  • Sections: images carousel, full description, specs, reviews
  • Actions: add to cart, favorite, share
Cart
  • Fields: list of items (id,qty,price,options), subtotal, discounts, shipping estimate
  • Format: editable quantities, persist in local storage/session server
Checkout
  • Fields: shipping address (name,addressLine1,addressLine2,city,state,zip,country,phone)
  • Payment method selection: saved card, new card, external wallets
  • Order summary and confirm button
Payment
  • Integration: third-party gateway (redirect or tokenized)
  • Fields (if card inline): cardNumber,expiry,cvc,cardholderName (PCI rules apply)
Orders
  • List view: orderId,date,status,total
  • Detail: items, tracking, invoices, cancellations
Profile & Settings
  • Profile: name,email,phone,avatar
  • Settings: notifications toggles, privacy options, language
Support / Contact
  • Ticket form: subject,category,message,attachments
  • Format: attachments accepted as file upload; follow-up messages thread
Notifications Center
  • Types: transactional, promo, system
  • Format: list with id,type,title,body,date,read

Detailed Pages & Fields — Admin App

Admin Login
  • Fields: email,password, 2FA code optional
  • Security: IP/role based restrictions, session timeout settings
Dashboard
  • Widgets: daily revenue, active users, pending orders, open tickets
  • Format: metric tiles, recent activity feed, charts
Users Management
  • List: userId,name,email,status,joinedDate,role
  • Detail: ability to edit profile, roles, impersonate, deactivate
Products / Content Management
  • Fields per product: id,title,description,price,images,inventory,category,attributes
  • Bulk import/export, versioning, publish/unpublish
Orders Management
  • Search & filters: by date, status, user, orderId
  • Actions: update status, refund, resend invoice, contact user
Support Tickets
  • Ticket fields: ticketId,userId,subject,category,status,assignedTo,messages
  • Workflow: triage → assign → respond → resolve
Reports & Analytics
  • Pre-built reports: sales, user growth, retention, support metrics
  • Export: CSV, XLSX; date-range chooser, chart types
Admin Settings & Roles
  • Role model: admin roles, permissions matrix
  • System settings: feature flags, integrations, webhooks
System Notifications
  • Manage templates, channels (email, push), schedules

Integration Points

  • Auth: central auth service used by both apps.
  • Orders: User orders appear in Admin Orders for fulfillment.
  • Support: User tickets map to Admin tickets for agents.
  • Notifications: Shared notification center and templates.
